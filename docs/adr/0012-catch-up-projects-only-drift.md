# Catch-up Projects only drifted Tasks

Refines ADR-0007. Projecting every Open Qualifying Task and every Bound Task each hour cost one Projection run per Task per hour, plus a Calendar write each time, even when nothing had changed. Catch-up now lists all Tasks (open and completed), every Binding, and every Event on the Calendar, and enqueues a Task only when: it is Open and Qualifying with no Binding; it is Bound and its Event is missing, its Event etag differs from the Binding (changed on the Calendar), or its Event no longer matches the Task's draft (missed Attio update); it is Bound and has no Deadline; it is Bound and Attio no longer lists it (Deletion); or its Binding points at another Calendar. Completed Tasks that were never Bound still stay off the Calendar. The Projection worker still re-reads both sides, so an extra enqueue is harmless. Catch-up stays hourly, because Heal and missed-webhook repair latency is unchanged and an in-sync run costs a handful of steps.
